What changed (TC-06 fixes)

  • ✓ Sidebar auto-hides on phones (< 768px); the ☰ button toggles it as an overlay drawer with a tap-to-dismiss backdrop.
  • ✓ Header padding shrunk from px-8 to px-3 sm:px-8; element gap from gap-6 to gap-2 sm:gap-6.
  • ✓ Breadcrumb pill hidden on phones (would overflow).
  • ✓ "System Admin / Master Control" text hidden on phones; avatar (AQ) stays visible.
  • ✓ Main viewport padding from p-10 to p-3 sm:p-6 lg:p-10 — reclaims ~74px of usable width on a 375px phone.
  • ✓ Footer trims long labels ("Platform v1.0.0", "Powered by AI") on phones so it stays on one line.
  • ✓ Notification bell shows a real dropdown panel (not a browser alert) with live counts of overdue invoices + low-stock products.

What's NOT yet mobile-polished

  • ⚠ Individual page contents (Customers list, Invoice form, Product Catalog, etc.) still use desktop-oriented grids. They'll horizontal-scroll on mobile but won't stack.
  • ⚠ Tables on mobile remain tables — they don't collapse into card lists. Page-by-page work required.
